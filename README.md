## Como registrar cada incidente

O professor dita o título. Copiar o modelo abaixo, com 2 a 3 linhas de justificativa (mecanismo técnico + trade-off). Evento relâmpago só entra se o grupo for chamado.

```markdown
## <título ditado pelo professor>
**Tipo:** ( rodada / relâmpago ) · **Voto:** ( A / B / C / D )
**Justificativa:** <2 a 3 linhas: mecanismo técnico + trade-off>
**Placar do grupo após esta decisão:** 🔥 __ · 💰 R$ __ mil · 🧹 __
```

Convenção de commit, um por rodada:

```text
decisao: R1 - opcao C (<resumo da justificativa em uma frase>)
pos-mortem: relatorio de incidente da madrugada
```

Relâmpagos podem ir no commit da rodada seguinte.
